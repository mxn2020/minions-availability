# Welcome to Minions Availability

We're excited to introduce **Minions Availability** — Availability snapshots, slot states, and change detection for tent reservations.

## What's Included

- **TypeScript SDK**: `npm install @minions-availability/sdk`
- **Python SDK**: `pip install minions-availability`
- **CLI**: `npm install -g @minions-availability/cli`

## Getting Started

Check out the [documentation](https://availability.minions.help) for a full guide.
