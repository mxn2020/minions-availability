---
title: Installation
description: Install Minions Availability packages
---

## TypeScript / Node.js

```bash
npm install @minions-availability/sdk minions-sdk
```

## Python

```bash
pip install minions-availability
```

## CLI

```bash
npm install -g @minions-availability/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
