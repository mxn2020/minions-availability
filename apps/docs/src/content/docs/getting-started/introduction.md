# Minions Availability

Availability snapshots, slot states, and change detection for tent reservations

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-availability/sdk`) — Core library for Node.js
- **Python SDK** (`minions-availability`) — Python bindings
- **CLI Tool** (`@minions-availability/cli`) — Command-line interface
- **Web App** — Interactive playground at [availability.minions.wtf](https://availability.minions.wtf)
